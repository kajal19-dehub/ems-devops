# Employee Management System (Java)

## Description
A console-based Employee Management System (EMS) built with Java. This project demonstrates **Maven build automation** and **Git version control** as part of a mini automated build & deployment pipeline.

## Features
- Add, update, delete, list, and search employees
- Persistent storage in JSON (`data/employees.json`)
- Runnable fat JAR using Maven Shade Plugin
- Version control with Git/GitHub

## Prerequisites
- Java 25+
- Maven 3.9+
- Git
